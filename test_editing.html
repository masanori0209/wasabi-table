📋 コピー&ペースト機能テスト:

Ctrl+V / Cmd+V
クリップボードからペースト
Ctrl+X / Cmd+X

🎯 テスト手順:

  1. 単一セル選択: セルをクリック → Ctrl+Cでコピー → 別のセルでCtrl+Vでペースト
  2. 範囲選択: セルをドラッグして範囲選択 → Ctrl+Cでコピー → 別の場所でCtrl+Vでペースト
  3. Excel連携: Excelでデータをコピー → NinjaTableでCtrl+Vでペースト
  4. カット機能: 範囲選択 → Ctrl+Xでカット → 別の場所でCtrl+Vでペースト
  5. 全選択: Ctrl+Aで全選択 → Ctrl+Cでコピー

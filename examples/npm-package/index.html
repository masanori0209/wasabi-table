🚀 高性能レンダリング

Rust + WebAssemblyによる最適化されたパフォーマンス。大規模データもスムーズに処理。

📊 Excel風操作

キーボードナビゲーション、セル編集、数式バーなど、Excelライクな操作感。

🎯 TypeScript対応

完全な型安全性とIntelliSenseサポート。JavaScript/TypeScript両方で利用可能。

🎨 カスタマイズ可能

豊富な設定オプションで、デザインや動作を自由にカスタマイズ。

📱 レスポンシブ

モダンブラウザ対応。WebAssemblyをサポートする環境で動作。

🪶 軽量

最小限の依存関係で、バンドルサイズを抑制。

🎮 操作方法

⌨️ キーボード操作

  • 矢印キー: セル移動
  • Enter: 編集開始 / 下のセルに移動
  • F2: 編集開始（既存値保持）
  • Tab: 右のセルに移動
  • Escape: 編集キャンセル
  • Delete/Backspace: セル内容削除
  • Ctrl+C / Cmd+C: コピー
  • Ctrl+X / Cmd+X: カット
  • Ctrl+V / Cmd+V: ペースト
  • Ctrl+Z / Cmd+Z: 元に戻す
  • Ctrl+Y / Cmd+Shift+Z: やり直し
  • Ctrl+A / Cmd+A: 全選択
  • Ctrl+矢印キー / Cmd+矢印キー: データの端まで移動（Excel風）
  • Shift+矢印キー: 範囲選択
  • Shift+Ctrl+矢印キー / Shift+Cmd+矢印キー: データの端まで範囲選択

🖱️ マウス操作

  • クリック: セル選択
  • Shift+クリック&ドラッグ: 範囲選択
  • ホイール: スクロール
  • ダブルクリック: 編集開始（予定）

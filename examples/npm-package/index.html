💻 使用方法

JavaScript での使用例

import { NinjaTable } from 'ninja-table';

async function initTable() {
  const canvas = document.getElementById('myCanvas');
  
  // テーブルを作成
  const table = await NinjaTable.create(canvas, {
    row_count: 50,
    col_count: 20,
    default_col_width: 120,
    default_row_height: 28
  });

  // セルに値を設定
  table.setCellValue(0, 0, 'Hello');
  table.setCellValue(0, 1, 'World');

  // イベントハンドラーを設定
  table.setEventHandlers({
    onCellSelect: (position) => {
      console.log(`選択: ${NinjaTable.getCellReference(position.row, position.col)}`);
    }
  });

  // レンダリング
  table.render();
}

initTable();

TypeScript での使用例

import { NinjaTable, TableConfig, CellPosition, EventHandlers } from 'ninja-table';

class SpreadsheetApp {
  private table: NinjaTable | null = null;

  async initialize(canvas: HTMLCanvasElement): Promise<void> {
    const config: Partial<TableConfig> = {
      row_count: 100,
      col_count: 26,
      default_col_width: 120,
      default_row_height: 28,
      font_family: 'Arial, sans-serif',
      font_size: 12
    };

    this.table = await NinjaTable.create(canvas, config);

    const handlers: EventHandlers = {
      onCellSelect: this.handleCellSelect.bind(this),
      onCellChange: this.handleCellChange.bind(this)
    };

    this.table.setEventHandlers(handlers);
    this.table.render();
  }

  private handleCellSelect(position: CellPosition): void {
    const cellRef = NinjaTable.getCellReference(position.row, position.col);
    console.log(`選択セル: ${cellRef}`);
  }

  private handleCellChange(position: CellPosition, oldValue: string, newValue: string): void {
    console.log(`セル変更: ${oldValue} → ${newValue}`);
  }
}

React での使用例

import React, { useEffect, useRef, useState } from 'react';
import { NinjaTable, TableConfig, CellPosition } from 'ninja-table';

const NinjaTableComponent: React.FC = () => {
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const [table, setTable] = useState<NinjaTable | null>(null);
  const [selectedCell, setSelectedCell] = useState<string>('A1');

  useEffect(() => {
    const initTable = async () => {
      if (!canvasRef.current) return;

      const config: Partial<TableConfig> = {
        row_count: 50,
        col_count: 20
      };

      const ninjaTable = await NinjaTable.create(canvasRef.current, config);
      
      ninjaTable.setEventHandlers({
        onCellSelect: (position: CellPosition) => {
          const cellRef = NinjaTable.getCellReference(position.row, position.col);
          setSelectedCell(cellRef);
        }
      });

      ninjaTable.render();
      setTable(ninjaTable);
    };

    initTable();

    return () => {
      if (table) {
        table.dispose();
      }
    };
  }, []);

  return (
    <div>
      <div>選択セル: {selectedCell}</div>
      <canvas ref={canvasRef} width={1000} height={400} />
    </div>
  );
};

export default NinjaTableComponent;

✨ 主な機能

🚀 高性能レンダリング

Rust + WebAssemblyによる最適化されたパフォーマンス。大規模データもスムーズに処理。

📊 Excel風操作

キーボードナビゲーション、セル編集、数式バーなど、Excelライクな操作感。

🎯 TypeScript対応

完全な型安全性とIntelliSenseサポート。JavaScript/TypeScript両方で利用可能。

🎨 カスタマイズ可能

豊富な設定オプションで、デザインや動作を自由にカスタマイズ。

📱 レスポンシブ

モダンブラウザ対応。WebAssemblyをサポートする環境で動作。

🪶 軽量

最小限の依存関係で、バンドルサイズを抑制。

🎮 操作方法

⌨️ キーボード操作

  • 矢印キー: セル移動
  • Enter: 編集開始 / 下のセルに移動
  • F2: 編集開始（既存値保持）
  • Tab: 右のセルに移動
  • Escape: 編集キャンセル
  • Delete/Backspace: セル内容削除

🖱️ マウス操作

  • クリック: セル選択
  • ホイール: スクロール
  • ダブルクリック: 編集開始（予定）

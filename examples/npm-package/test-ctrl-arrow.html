📋 テスト用キーボードショートカット

  • Ctrl+↑/↓/←/→ (Mac: Cmd+↑/↓/←/→): データの端まで移動
  • Shift+Ctrl+↑/↓/←/→ (Mac: Shift+Cmd+↑/↓/←/→): データの端まで範囲選択
  • 矢印キー: 1セルずつ移動
  • Shift+矢印キー: 1セルずつ範囲選択
